# Smart Mobility Platform

Plateforme Data/IA de mobilité inspirée des problématiques rencontrées dans les systèmes de transport modernes.

## Objectifs

- Recherche de trajets
- API FastAPI
- Base PostgreSQL
- Analyse Power BI
- Prédiction des retards avec Machine Learning
- Pipelines Data avec Airflow
- Azure Data Lake
- Google BigQuery
- Assistant IA avec Claude

## Architecture

- Frontend : React
- Backend : FastAPI
- Database : PostgreSQL
- Data Processing : Python / Pandas
- Machine Learning : Scikit-learn
- Orchestration : Airflow
- Cloud : Azure + GCP
- Generative AI : Claude
